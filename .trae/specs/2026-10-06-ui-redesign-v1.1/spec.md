# OMPlayer 界面重构 v1.1.001 - 产品需求文档

## Overview
- **Summary**: 以遥控器 10 尺交互为中心重构播放器界面：左侧「分类→频道→EPG」三级抽屉，右侧设置中心，重组底部控制面板，重做退出确认框；新增画面比例调节、分类显隐、节目源/EPG 源应用内管理窗口、EPG 回看。
- **Purpose**: 消除左右两个独立面板的割裂感，让 EPG 与选台在同一空间完成；设置项按使用频率重新组织；补齐参考产品（DIYP 系）已被用户验证的交互范式。
- **Target Users**: Windows  HTPC/遥控器用户与安卓电视盒子用户（无鼠标、仅遥控器操作）。

## Goals
- 左侧抽屉三级结构：一级节目分类、二级频道（选中即弹出该频道三级 EPG）、三级 EPG（预报+回看）。
- 右侧设置中心：画面比例、超时换源、分类管理、列表管理（节目源/EPG 源）、偏好设置，全部遥控器可达。
- 控制面板：删除二维码按钮；EPG 按钮改为打开节目源管理窗口；设置按钮弹出右侧菜单；节目列表按钮保留。
- 菜单键：单击弹出/收起右侧设置菜单；取消长按菜单键呼出设置。
- 返回键严格层级返回；无任何面板时弹退出确认框。
- 退出框：无标题、仅提示语，「取消 / 退出程序 / 关闭系统」三按钮居中；安卓隐藏关机按钮。
- 版本号跳到 1.1.001。

## Non-Goals
- 不改播放内核（fvp/MDK、source 加载解析主流程、DLNA/投屏、remote admin HTTP 服务内部逻辑）。
- 不改点播 seek OSD、切台防抖、Windows 低级钩子双通道修复等近期已稳定的行为。
- 缓冲时间设置从 UI 移除（模型字段保留以免破坏性改动，不再暴露入口）。
- 不做 EPG 收藏、搜索等参考图之外的新功能。

## Background & Context
- 参考图（用户提供 10 张）：三级抽屉（频道组｜频道｜EPG 时间轴+预约/直播文字按钮）、右侧双列设置菜单及画面比例/分类管理/列表订阅/EPG 订阅/分组配置子弹层、退出框样式。
- 现状关键事实（已勘察）：
  - `LeftChannelDrawer`（两级）与 `RightEpgPanel` 是两个独立 widget；EPG 选中/预约逻辑近期已修复（稳定标识、频道 ID 一致性、粗跳定位），重构需保留这些成果。
  - `PlayerSettings` 已有 launchAtStartup、startFullscreen、showClock、alwaysOnTop、dlnaEnabled、sourceTimeoutSeconds、remoteAdminEnabled 等字段；缺画面比例模式与隐藏分类。
  - 视频渲染在 `video_player_widget.dart`：`FittedBox(BoxFit.contain)` + 按视频尺寸/16:9 的 `SizedBox`，画面比例模式可在 widget 层实现，无需内核改动。
  - `EpgProgram`/XMLTV 解析器无 catchup 字段；`Channel` 有 userAgent 但无 catchup 参数。
  - `SourceManager` 已有 playlists/epgs 的增删改切换与 SharedPreferences 持久化；remote admin 已有 `/api/snapshot`、`/api/refresh`。
  - `auto_launch_io.dart` 已实现桌面端开机自启；项目内无任何关机代码。
  - `PlayListSource` 无 headers 字段（本期不扩展）。
- 已确认的需求决策（用户 2026-10-06 回答）：
  1. 回看：**所有过期节目都显示「回看」按钮**；有源地址时播放，无时提示「该节目暂不支持回看」。
  2. 关机：安卓隐藏「关闭系统」按钮；Windows/Linux 显示并执行系统关机。
  3. 控制面板原 EPG 按钮：改为打开节目源管理（列表订阅）窗口。
  4. 超时换源子菜单：开关 + 等待时间（5/10/15/20 秒）。
- 老 `SettingsPanel` 中未被用户点名但需保留的设置（视频画质、自动播放下一频道、面板自动隐藏、界面缩放、手机扫码管理开关）并入右侧「偏好设置」子页；缓冲时间、手势灵敏度不再暴露入口。

## Functional Requirements

### 左侧三级抽屉
- **FR-1**: 抽屉从左侧滑出，最多三列：一级分类（窄列）、二级频道（中列）、三级 EPG（宽列）；半透明深色材质，参考图风格。
- **FR-2**: 一级列出「我的收藏」虚拟分类（固定在最前、始终显示、不受分类显隐开关影响）+ 所有「未隐藏」的真实分类；上下移动、OK/右键进入二级；左键/返回在一级时关闭抽屉。
- **FR-2a**: 「我的收藏」聚合所有已收藏频道（按频道在源中的原始顺序排列）；无收藏时二级显示空态「还没有收藏频道，在频道上长按 OK 收藏」；在该分类下短按 OK 同样播放。
- **FR-3**: 二级列出来该分类频道（含序号、台标、名称，已收藏频道带心形标记）；上下移动选中；选中项变化时三级 EPG 自动切换为该频道节目单（不触发播放）；**短按 OK 播放该频道并关闭抽屉；长按 OK（约 500ms）收藏/取消收藏该频道**（SnackBar 提示「已收藏」/「已取消收藏」，「我的收藏」列表即时增减，频道 ID 不变、不影响预约）；左键回一级。
- **FR-4**: 三级 EPG 在二级获得焦点时自动出现；右键进入三级（焦点移入），左键回到二级；三级内部有两个焦点区：顶部「日期选择条」与下方节目列表。进入三级时焦点默认在节目列表（定位当前节目）；在列表第一项继续向上→焦点进入日期选择条，日期条上左右切换日期、向下回节目列表；列表内上下移动节目，条目始终保持在可视区中部（沿用粗跳+ensureVisible 策略）。
- **FR-4a**: 日期选择条：按 EPG 数据中实际存在的日期生成可选日期（含过去日期与未来日期），每个日期显示「周X MM-DD」，当天标注「今天」、次日「明天」（参考图样式），当天默认选中；左右移动即时切换，下方节目列表过滤为所选日期 00:00–24:00 的节目；所选日期无数据时列表区显示「该日期暂无节目单」。日期范围受频道 catchup-days（回看天数）与 EPG 数据覆盖范围共同约束。
- **FR-5**: EPG 条目布局与参考图对齐：最前面一列显示「周X」与「MM-DD」日期，其后为时间段（HH:00 - HH:00）、节目名，最右侧为状态/操作，状态优先级如下：
  1. 当前正在播放：「直播」徽标（红色）；
  2. 未播出且未预约：文字按钮「预约」；
  3. 未播出且已预约：高亮「已预约」（琥珀色，再按 OK 可取消）；
  4. 已播出、且该节目曾被预约并已触发执行：**灰色置灰按钮「已播放」，不可再操作**（OK 仅轻提示或无动作，不能再取消/回看）；
  5. 已播出、其余情况：文字按钮「回看」。
- **FR-5a**: ReservationManager 需暴露「预约是否已触发执行」查询（基于现有 `_triggeredIds`，按与预约记录相同的 id 构造规则比对），供 EPG 条目判定第 4 种灰态；已触发状态已持久化，重启程序后灰态保持。
- **FR-6**: 三级内 OK：未播节目=预约/取消预约切换并 SnackBar 提示（沿用现有 ReservationManager 与频道 ID 一致化逻辑）；过期节目=尝试回看播放，不支持时提示。
- **FR-7**: 打开抽屉时默认定位：当前频道所在分类→当前频道→当前/下一个节目；自动滚动到可视位置。
- **FR-8**: 触发入口：控制面板「节目列表」按钮、直播态短按 OK（现有行为）、键盘 C 键；点播短按 OK 行为不变（播放/暂停），不弹抽屉。

### 右侧设置中心
- **FR-9**: 右侧滑入式菜单，一级纵向列表：画面比例、超时换源、分类管理、列表管理、偏好设置；右/OK 进入子级，左/返回回一级，一级再返回关闭。
- **FR-10**: 画面比例子级：默认、16:9、4:3、填充、原始、裁剪 共 6 项，当前项高亮，选择即时生效并持久化；切台/重启保持。
- **FR-11**: 超时换源子级：超时换源开关；等待时间选项 5/10/15/20 秒；改动即时保存。
- **FR-12**: 分类管理子级：列出全部**真实**播放列表分类（不含「我的收藏」虚拟分类），每行名称+开/关状态，OK 切换显隐并即时持久化；被隐藏分类不出现在左侧一级列表，且上下切台循环跳过。
- **FR-13**: 列表管理子级含「节目源设置」「EPG 源设置」两行，分别打开应用内窗口：二维码（remote admin 地址）、已订阅源列表（当前源勾选、复制、删除）、名称(选填)+URL 输入、确定按钮；确定后保存并刷新。
- **FR-14**: 偏好设置子级：自启动、窗口置顶、启动最大化、显示时钟、投屏接收、手机扫码管理开关，以及视频画质、自动播放下一频道、面板自动隐藏、界面缩放选项；全部即时生效（沿用现有 controller 生效逻辑）。
- **FR-15**: 触发入口：控制面板「设置」按钮、遥控器菜单键单击、键盘 S 键（保留）。

### 控制面板
- **FR-16**: 删除「手机扫码管理」二维码按钮；原「节目单/EPG」按钮改为「节目源」按钮，点击打开节目源管理窗口（FR-13）；「节目列表」按钮保留（打开左侧抽屉）；「设置」按钮打开右侧设置中心；其余按钮（切源、播放暂停、截图、录制、旋转、断开投屏）不变。

### 按键层级
- **FR-17**: 菜单键单击=切换右侧设置中心（开→关、关→开）；取消长按 500ms 呼出旧设置面板的逻辑；菜单键在弹层内仍承担「关闭当前弹层」语义。
- **FR-18**: 返回键层级：右侧设置子级→一级→关闭；左侧抽屉三级→二级→一级→关闭；应用内对话框→关闭；底部面板→关闭；以上皆无→退出确认框。连按不重入、不双 pop（沿用 v1.0.145 守卫）。
- **FR-19**: 右侧设置中心打开期间，上下为列表内导航、左右为进出子级、OK 为进入/切换；不穿透到视频（不切台、不 seek）。

### 退出确认框
- **FR-20**: 无标题栏，仅一句提示语；按钮水平居中排列：取消、退出程序、关闭系统；安卓/iOS 构建只显示前两个。
- **FR-21**: 左右移动高亮（取消蓝、退出红、关机橙），OK 执行；返回/Esc/菜单=取消；点击执行：退出程序沿用现有 windowManager.close/SystemNavigator.pop；关闭系统在 Windows 执行 `shutdown /s /t 0`、Linux 执行 `poweroff`，执行前 SnackBar 提示。

### 回看
- **FR-22**: M3U 解析读取 `catchup`、`catchup-source`、`catchup-days` 参数到 Channel；构造回看 URL 时按常见模板（`{start}`、`{end}`、`{utc}`、`{duration}` 占位符，Unix 时间）替换。
- **FR-23**: 过期节目「回看」OK：能构造地址→用该地址播放（不影响当前频道订阅状态）；不能→SnackBar「该节目暂不支持回看」。

### 版本与品牌
- **FR-24**: pubspec.yaml 版本改为 1.1.001+2001（版本名 1.1.001）。
- **FR-25**: 应用图标更换为用户选定的「视频取景框」方案（深色圆角方块 + 青紫取景框角标线 + 白色 OM + 右下青色播放圆钮）；仓库提交各尺寸品牌资源，CI 在 `flutter create` 生成平台工程后覆盖默认图标：Android 五档 mipmap、Windows app_icon.ico、Web Icon-192/512 与 favicon。

## Non-Functional Requirements
- **NFR-1**: 全部新界面可仅凭遥控器完成操作（无鼠标），焦点框清晰可见，滚动定位准确。
- **NFR-2**: Windows、Android、Web、Linux CI 四平台构建通过。
- **NFR-3**: 播放核心行为零回归：切台防抖、点播 ±60s seek OSD、预约定时触发、DLNA、网页频道、录制截图不受影响。
- **NFR-4**: 界面中文，深色半透明风格与参考图一致，4K 缩放（ScaledPanel 体系）下不变形。
- **NFR-5**: 新增设置项全部持久化（SharedPreferences），重启保持。

## Constraints
- **Technical**: Flutter 3.44.8（CI）；本机无 Flutter SDK，仅能靠 GetDiagnostics + CI 验证；qr_flutter 4.1.0（QrEyeShape/QrDataModuleShape 仅 square/circle）；视频几何只在 widget 层实现。
- **Business**: 主要模块不动；不引入新的原生依赖（关机用 Process.run 调系统命令；安卓不实现关机）。
- **Dependencies**: SourceManager/ReservationManager/remote admin 现有 API；window_manager；auto_launch_io。

## Assumptions
- 「启动最大化」复用现有 startFullscreen 语义（启动进入全屏/最大化）。
- 界面缩放沿用 uiScale/uiScaleAuto 现有机制，放入偏好设置。
- 回看 URL 模板兼容 DIYP/标准 IPTV catchup 约定；不支持的源按 FR-23 降级提示。
- 旧 SettingsPanel 的引用全部迁移后其文件删除，避免双套设置入口。
- 右侧菜单与左侧抽屉互斥：打开一个时另一个自动关闭。

## Acceptance Criteria

### AC-1: 三级抽屉导航规则
- **Type**: `rule`
- **Given**: 直播播放中、无任何面板
- **When**: 依次进行：打开抽屉→一级上下→右键进二级→上下移动频道→右键进三级→在节目列表首项继续向上进入日期选择条→左右换一天→向下回列表→上下移动节目→左键回二级→左键回一级→返回关闭
- **Then**: 焦点列/焦点区每步正确；二级移动时三级 EPG 随频道切换但不播放；换日期时列表过滤为该天节目；返回层级严格为三级→二级→一级→关闭
- **Pass Condition**: 代码走查 `handleRemoteKey` 状态机（含日期条焦点区）与上述路径一一对应；构建产物中该交互可执行
- **Evidence**: 代码审查 + 设备实测记录

### AC-2: 打开即定位当前频道与当前节目
- **Type**: `rule`
- **Given**: 当前频道在分类与频道列表中任意位置（包括很靠后）
- **When**: 打开左侧抽屉
- **Then**: 自动进入当前频道所在分类、二级滚动到当前频道、三级默认选中今天并滚动到当前播放节目（可视区中部）
- **Pass Condition**: 三列均使用「粗跳+ensureVisible」两阶段定位；当前频道/节目有高亮；日期条默认选中今天
- **Evidence**: 代码审查 + 实测

### AC-2b: 按日期筛选 EPG
- **Type**: `rule`
- **Given**: 当前频道 EPG 覆盖前几天与后几天（或至少多天）
- **When**: 三级内上移到日期选择条，左右切换到过去某天与未来某天
- **Then**: 日期条项显示「周X MM-DD」、今天/明天有标注；节目列表仅显示所选日期的节目（过去日期可回看、未来日期可预约）；无数据日期显示「该日期暂无节目单」；可选日期不超出 EPG 数据范围与 catchup-days 回看窗口
- **Pass Condition**: 日期集合由节目数据聚合 + catchup-days 约束；过滤逻辑按自然日 00:00–24:00；空态文案存在
- **Evidence**: 代码审查 + 实测

### AC-2c: 频道收藏
- **Type**: `rule`
- **Given**: 左侧抽屉二级频道列表
- **When**: 在某频道长按 OK（≥500ms）→进入「我的收藏」→在收藏分类中对该频道再长按 OK
- **Then**: 首次提示「已收藏」、频道行出现心形、「我的收藏」即时出现该频道；再次长按提示「已取消收藏」、心形消失、移出收藏；短按 OK 始终是播放不被收藏打断；收藏名单独立持久化（重启保持），频道 id 与既有预约记录不受收藏/取消影响
- **Pass Condition**: 收藏存储为独立 ID 集合（不修改 Channel/分类结构）；短按/长按判定有计时器且长按时短按动作不触发；「我的收藏」固定一级首位且空态文案存在
- **Evidence**: 代码审查 + 实测

### AC-3: EPG 预约、已执行灰态与回看按钮
- **Type**: `rule`
- **Given**: 三级 EPG 列表中存在未播未预约、未播已预约、直播中、已播且预约已触发、已播普通 五类节目
- **When**: 观察按钮状态；对未播节目按 OK→再次按 OK；对「已播放」灰态按 OK；对普通过期节目按 OK
- **Then**: 五类按钮依次为「预约」「已预约(琥珀)」「直播徽标」「已播放(灰色置灰)」「回看」；未播首次预约、再次取消；灰态不可操作（不取消、不回看）；普通过期节目有回看地址则播放、无地址提示「该节目暂不支持回看」；重启程序后灰态保持
- **Pass Condition**: 按钮渲染五级优先级与 OK 分支代码满足；灰态判定走 ReservationManager 已触发查询（_triggeredIds 持久化）；预约状态查询与存储频道 ID 解析一致
- **Evidence**: 代码审查 + 实测

### AC-4: 右侧设置中心结构与进出
- **Type**: `rule`
- **Given**: 视频播放中
- **When**: 单击菜单键→右侧菜单出现→依次进入并退出五个子级→返回关闭
- **Then**: 一级恰好 5 行（画面比例/超时换源/分类管理/列表管理/偏好设置）；子级内容符合 FR-10~FR-14；返回层级为子级→一级→关闭；打开期间方向键/OK 不穿透到视频
- **Pass Condition**: 菜单 widget 路由状态机与按键处理代码满足；穿透守卫存在
- **Evidence**: 代码审查 + 实测

### AC-5: 画面比例即时生效
- **Type**: `rule`
- **Given**: 右侧设置→画面比例
