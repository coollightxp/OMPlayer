# OMPlayer

跨平台 Flutter 直播流媒体播放器，支持播放列表管理、EPG 节目单、节目预约、录制截图、DLNA 投屏接收。

## 功能特性

- 📺 **直播播放**：支持 HLS/DASH 等直播流播放
- 📋 **播放列表管理**：支持 M3U / TXT 格式，URL 或本地文件导入
- 📅 **EPG 节目单**：XMLTV 格式解析，支持多 EPG 源切换
- ⏰ **节目预约**：到时间自动切换到对应频道
- 🎬 **录制与截图**：桌面端录制/截图，文件保存到程序所在文件夹的 `recordings` / `screenshots` 子文件夹
- 📡 **DLNA 投屏接收**：启动即开启，手机等设备可把视频投到本机播放；设备名为 `OMPlayer + 机器标识`；投屏断开后自动恢复之前的播放状态
- 🎚️ **手势控制**：左侧上下滑调亮度，右侧上下滑调音量
- 🗂️ **两级抽屉**：左侧频道分类抽屉，右侧 EPG 节目面板
- 🖥️ **窗口置顶**：全屏时窗口自动置顶，不被其它窗口覆盖
- ⚙️ **系统设置**：开机启动、启动全屏（仅启动时检测一次）、右上角显示系统时钟；标题栏默认隐藏，鼠标移到顶部悬停呼出（最小化/最大化/关闭），打开频道/EPG/设置面板时自动让位

## 平台支持

| 平台 | 支持状态 |
|------|---------|
| Android | ✅（强制横屏，支持挖孔屏全屏） |
| Web | ✅ |
| Windows | ✅（含录制/截图/DLNA 接收） |
| Linux | ✅（含录制/截图/DLNA 接收） |

> 桌面端录制功能由内置 fvp(MDK) 完成，无需额外安装 ffmpeg。

## 键盘快捷键（桌面端）

| 功能 | 快捷键 |
|------|--------|
| 全屏 / 恢复窗口 | `F` 或 `F11`（也可双击画面） |
| 暂停 / 播放 | `空格` |
| 截屏 | `PrintScreen` |
| 录制 / 停止录制 | `R` |
| 静音 / 恢复音量 | `M` |
| 上一节目 / 下一节目 | `↑` / `↓` |
| 上一节目源 / 下一节目源 | `←` / `→` |
| 打开 / 关闭节目列表 | `C` |
| 打开 / 关闭 EPG 节目单 | `E` |
| 设置面板 | `S` |
| 画中画小窗 / 恢复 | `P` |
| 退出全屏 | `Esc` |

鼠标：单击画面中部的边缘区域打开左侧频道列表 / 右侧 EPG；单击中间显示/隐藏底部面板；双击切换全屏（移动端双击为播放/暂停）。

## DLNA 投屏接收

- 程序启动时自动开启 DLNA（MediaRenderer）服务
- 设备名格式：`OMPlayer-机器名`（如 `OMPlayer-DESKTOP-ABC123`）
- 手机/平板在同一局域网内用支持 DLNA 的视频 App（哔哩哔哩、腾讯视频、Ace Cast 等）选择该设备即可投屏
- 投屏端点「停止/断开」后，自动恢复投屏之前的频道播放
- Windows 如无法被发现，请检查防火墙是否放行 OMPlayer（UDP 1900 及随机 HTTP 端口）

## 自动构建

推送代码到 `main` 分支后，GitHub Actions 会自动构建以下产物：

- Android APK（arm64-v8a / armeabi-v7a / x86_64）
- Web 静态站点
- Windows 桌面应用（zip）
- Linux 桌面应用（zip）

构建产物可在仓库的 **Actions** 页面下载，或在发布 **Release** 时自动附加到发行版。

## 本地构建

```bash
flutter pub get
flutter run
```

```bash
flutter config --enable-windows-desktop
flutter build windows --release
```

## 使用说明

1. 点击中间区域调出底部控制栏，点击设置按钮
2. 在「播放列表」标签页添加 M3U/TXT 源（URL 或本地文件）
3. 在「EPG」标签页添加 XMLTV 节目单地址
4. 从左侧抽屉选择频道开始播放
5. 右侧面板查看节目单并预约节目
