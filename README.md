# OMTV（欧米电视）

跨平台 Flutter 电视直播播放器：频道与节目单内置央视频来源，支持节目预约、录制截图、DLNA 投屏接收、听电视与锁定。

## 功能特性

- 📺 **直播播放**：央视频网页源（1080P / 720P / 540P 可切换），复用内嵌网页播放链路
- 🗂️ **内置频道表**：央视频道、卫视频道、数字付费、教育频道，台标随包内置
- 📅 **内置节目单**：央视频 EPG，启动时后台拉取，每 15 分钟自动刷新
- ⏰ **节目预约**：到时间自动切换到对应频道
- 🎧 **听电视**：只保留声音；手机/平板显示信息卡片（上一台/下一台、暂停/继续），Windows 可隐藏窗口
- 🔒 **锁定**：屏蔽误触，返回键 / `Esc` / `L` 解锁
- 🪟 **小窗播放**：移动端缩小画面浮层，桌面端缩小窗口并置顶
- 🎬 **录制与截图**：录制/截图保存到程序目录的 `recordings` / `screenshots` 子文件夹
- 📡 **DLNA 投屏接收**：启动即开启，手机等设备可把视频投到本机播放；设备名为 `OMTV + 机器标识`；投屏断开后自动恢复之前的播放状态
- 🎚️ **手势控制**：左侧上下滑调亮度，右侧上下滑调音量
- 🖥️ **窗口置顶**：全屏时窗口自动置顶，不被其它窗口覆盖

## 平台支持

| 平台 | 支持状态 |
|------|---------|
| Android | ✅（强制横屏，支持挖孔屏全屏） |
| Web | ✅ |
| Windows | ✅（含录制/截图/DLNA 接收） |
| Linux | ✅（网页频道回退系统浏览器） |

> 桌面端录制功能由内置 fvp(MDK) 完成，无需额外安装 ffmpeg。

## 键盘快捷键（桌面端）

| 功能 | 快捷键 |
|------|--------|
| 全屏 / 恢复窗口 | `F` 或 `F11`（也可双击画面） |
| 暂停 / 播放 | `空格` |
| 截屏 | `PrintScreen` |
| 录制 / 停止录制 | `R` |
| 静音 / 恢复音量 | `M` |
| 听电视 | `T` |
| 锁定 / 解锁 | `L` |
| 上一频道 / 下一频道 | `↑` / `↓` |
| 打开 / 关闭节目列表 | `C` |
| 打开 / 关闭 EPG 节目单 | `E` |
| 设置面板 | `S` |
| 退出全屏 / 逐层关闭 | `Esc` |

鼠标：鼠标移到左/右/底部边缘呼出频道列表 / EPG / 控制栏；双击切换全屏；右键相当于返回键。

## DLNA 投屏接收

- 程序启动时自动开启 DLNA（MediaRenderer）服务
- 设备名格式：`OMTV-机器名`（如 `OMTV-DESKTOP-ABC123`）
- 手机/平板在同一局域网内用支持 DLNA 的视频 App（哔哩哔哩、腾讯视频、Ace Cast 等）选择该设备即可投屏
- 投屏端点「停止/断开」后，自动恢复投屏之前的频道播放
- Windows 如无法被发现，请检查防火墙是否放行 OMTV（UDP 1900 及随机 HTTP 端口）

## 自动构建

推送代码到 `main` 分支后，GitHub Actions 会自动构建以下产物：

- Android APK（arm64-v8a / armeabi-v7a / x86_64）
- Web 静态站点
- Windows 桌面应用（zip）
- Linux 桌面应用（zip）

构建产物可在仓库的 **Actions** 页面下载，或在发布 **Release** 时自动附加到发行版。

## 本地构建

```bash
flutter pub get
flutter run
```

### 桌面端

```bash
flutter config --enable-windows-desktop
flutter build windows --release
```

## 使用说明

1. 启动后等待节目单初始化完成（显示启动图）
2. 鼠标移到屏幕左边缘或点击左侧按钮打开频道列表，选择频道播放
3. 底部控制栏可切换播放/暂停、全屏/小窗、静音、听电视、锁定、设置与清晰度
4. 右侧面板查看节目单并预约节目
